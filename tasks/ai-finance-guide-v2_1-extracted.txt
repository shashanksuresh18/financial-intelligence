TOOL 02

FinBERT — Sentiment Analysis Built for Finance

ProsusAI/ﬁnbert · BERT ﬁne-tuned on ﬁnancial text

What It Is

A BERT-based model ﬁne-tuned on ﬁnancial news

capable of assigning positive, negative, or neutral

sentiment to ﬁnancial text. Unlike general models, FinBERT

understands that "margin pressure" is negative and

"sequential improvement" is positive.

How YOU Use It

Pull daily news headlines for a watchlist of stocks. Run

each headline through FinBERT. Compute a 7-day rolling

average sentiment score per company. Plot against price.

Look for divergences — where sentiment has moved but

price has not yet followed.

TOOL 03

FinQA Dataset — Where Real Finance AI Gets Tested

czyssrs/FinQA · Numerical reasoning · Built by ﬁnancial experts

What It Is

A research-grade dataset of complex ﬁnancial questions

from SEC ﬁlings and earnings documents. Tests a model's

ability to reason mathematically over real ﬁnancial

reports.

Insider Insight

FinQA is not just a dataset — it is a philosophy. Real

ﬁnancial intelligence requires multi-step numerical

reasoning over long documents, not keyword retrieval.

Any AI system you build for ﬁnance should pass a

FinQA-style test before you trust it with actual

decisions.

github.com/czyssrs/FinQA

SECTION 06

Real Talk — What Nobody Tells

You About FinGPT

Data quality is everything:

FinGPT is only as good as the ﬁnancial data it

was trained on. Noisy inputs produce degraded outputs.

—

Fine-tuning is required for precision:

Out-of-the-box FinGPT performs

well on general ﬁnancial tasks. For Indian regulatory ﬁlings or SEBI circulars,

you need domain-speciﬁc ﬁne-tuning.

—

Use-case design matters more than the model:

Two people using the

same FinGPT model with different prompts will get dramatically different

results.

—

It is not a trading system:

FinGPT does NLP. It reads and understands text. It

does not run quantitative backtests, build factor models, or predict prices.

—

Overﬁtting to historical data kills models:

Markets change regime. COVID

changed regime. Rate cycles change regime. Models must be continuously

retrained.

—

The yield curve (10Y–2Y spread) is the most historically

reliable recession predictor. Every rate cycle analysis,

bond model, and macro regime ﬁlter needs FRED data.
